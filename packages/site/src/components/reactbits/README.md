# React Bits

Components copied verbatim from [React Bits](https://reactbits.dev/)
(`src/ts-default` in [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits)),
under the MIT + Commons Clause licence in `LICENSE.md`.

They are vendored, not depended on — React Bits is a copy-paste library, not an
npm package. Keep them unedited so an update is a plain re-copy; adapt them by
wrapping, not by patching. That is also why the root ESLint config ignores this
folder.
